# Hub Server Utility Plugin  

---

## 説明 / Description

このプラグインはHub Serverのために作られた汎用プラグインです。  
Hub Serverに必要な機能をそろえていきたいとおもいます。  

---
## 機能 / feature
初期スポーンポイント: 
    プレイヤーがサーバーに入ったときに、任意の場所にスポーンさせる機能です。
---

## Command Usage  

/hubserverutility, /hsu:
このプラグインの機能に関するGUIを表示します。  

(以下コマンドは "/hsu" と書く)  

/hsu initialspawn  
プレイヤーが現在いる座標、向きを取得して、保存します。  
-Tips-   
/hsu isに省略が可能

/hsu is "x" "y" "z" "yaw" "pitch"  
任意の座標と向きを保存します。
